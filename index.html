데이터스트림즈에는 인턴으로 입사해 수년간 쌓인 레거시를 걷어내며 고객사 버그 70건을 모두 해결하고 정규직으로 전환됐습니다. 5년 넘게 원인이 밝혀지지 않던 PostgreSQL ODBC 접속 오류는 재현 환경부터 다시 만들어 DSN 캐싱이라는 근본 원인을 짚어냈고, 예약 실행의 CRON 파싱 구조를 바꿔 성능을 60% 끌어올렸습니다. 세마포어·세션 수 기본값이 병목이라는 걸 찾아 배치 처리 시간을 40% 줄인 것도 같은 방식이었습니다.

에스앤디에서는 경기도 자율주행 플랫폼의 83개 솔루션을 정기점검하며, 장애가 나면 로그를 분석해 원인 범위를 좁히고 담당 업체와 협의해 마무리했습니다. TCP 소켓 기반 실시간 전송 모듈과 로그 자동 수집·SMS 알림 모니터링 시스템도 직접 만들었습니다. 지금은 삼성청년 SW·AI아카데미에서 Java와 Spring 기반 웹 개발을 다시 다지고 있습니다.
